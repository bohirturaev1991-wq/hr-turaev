# hr-turaev.uz

Персональный сайт Bohir Turaev — рекрутинг и HR-стратегия на аутсорсе (Ташкент).

Статический сайт на HTML/CSS/JS, два языка (RU / UZ).

- `index.html` — главная страница
- `styles.css` — стили
- `script.js` — тексты на двух языках и переключатель
- `blog/` — статьи
- `images/`, `files/` — фото и материалы для скачивания

Чтобы посмотреть локально, откройте `index.html` в браузере.
